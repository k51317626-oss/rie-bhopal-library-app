# RIE Bhopal Library PWA

This folder contains a ready-to-upload Progressive Web App (PWA) website.

## Upload to GitHub Pages
1. Open your `rie-bhopal-library-app` repository.
2. Upload the CONTENTS of this folder (not the ZIP itself) to the repository root.
3. If GitHub asks whether to replace `index.html`, `manifest.json`, or `sw.js`, choose the replacement option.
4. Keep the `icons` folder and both PNG icon files.
5. Commit the changes to the `main` branch.
6. Wait for GitHub Pages to redeploy, then open your website in Chrome.

## Install on Android
1. Open the GitHub Pages URL in Chrome.
2. Wait for the page to finish loading.
3. Open Chrome's ⋮ menu. If available, choose **Install app** or **Add to Home screen**.
4. If Chrome still says it cannot be installed, use **Add to Home screen** if offered; otherwise check that the manifest and service worker files have deployed successfully.

## Important
- PWA installation depends on browser/device support and successful HTTPS deployment.
- Some external links may require institutional access or login.
- This portal does not collect passwords or library credentials.
