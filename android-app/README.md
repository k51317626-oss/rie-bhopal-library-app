# This app uses a WebView wrapper around the GitHub Pages version of the library app.
# Open this folder in Android Studio and run it on an emulator or device.

## Build steps
1. Open Android Studio.
2. Choose `Open an existing project`.
3. Select the `android-app` folder.
4. Let Gradle sync complete.
5. Run the app on an emulator or connected device.

## Notes
- The app loads the GitHub Pages URL for the library app.
- If GitHub Pages is not published yet, the WebView will not display content until it is enabled.
- The app includes internet permission for the library links and pages.
